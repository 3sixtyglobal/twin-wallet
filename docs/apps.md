# Wallet Applications

## wallet-cli

This app provides a command-line workflow for creating wallets, requesting funds from configured faucets, and transferring value between addresses. It helps operators and developers run wallet operations quickly from a terminal while sharing the same connector-driven behaviour used in library integrations.
